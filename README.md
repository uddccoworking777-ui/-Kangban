# 康伴 健康照護電商網站

前台網站和管理後台都在這個專案裡。不需要另外安裝資料庫，也不需要 Odoo。

- 前台：http://localhost:3000
- 後台：http://localhost:3000/admin

## 執行方式（Windows）

1. 安裝 [Node.js](https://nodejs.org) **LTS 版**（需要 22.13 以上）。
2. 解壓縮 `kangban-shop.zip`。
3. 打開 `kangban-shop` 資料夾（裡面要能看到 `package.json`），在上方路徑列輸入 `cmd` 並按 Enter。
4. 第一次使用，先輸入 `npm install`。
5. 輸入 `npm start`。
6. 打開瀏覽器，前往 http://localhost:3000/admin，建立第一個管理員帳號（擁有者）。

第一次啟動時，網站會自動放入原站的 5 項商品和 7 個分類當作起始資料。

> 這一版的優化內容、修改原因、測試結果和前後對照截圖，請看 [`docs/優化流程.md`](docs/優化流程.md)。

## 後台功能

| 頁面 | 功能 |
|---|---|
| 總覽 | 待辦事項（待確認付款、待出貨、未處理訊息、低庫存）、營收圖（可切換 7／30／90 天）、熱銷商品 |
| 訂單 | 逐步處理（確認收款 → 出貨 → 完成）、批次處理、列印出貨單、搜尋、日期篩選、匯出 CSV、處理紀錄 |
| 商品 | 新增、編輯、複製、刪除；上傳多張圖片；醫療器材資訊、規格、尺寸表、注意事項；列表直接改庫存、排序；批次上架、下架、刪除 |
| 分類 / 品牌 | 新增、編輯、刪除，可上傳圖示和 Logo，支援子分類和排序 |
| 客戶 | 會員和訪客清單、訂單數、累計消費、客戶詳細資料、重設密碼、匯出 CSV |
| 客服訊息 | 「聯絡我們」表單收到的訊息，可標記已處理並寫備註 |
| 匯入商品 | 從 **Google 試算表** 或 CSV 匯入，匯入前會先預覽 |
| 設定 | 公司資訊、網站公告、客服資訊、社群連結、運費、免運門檻、匯款帳號、Google API |
| 全站搜尋 | 頁首搜尋框（按 `/`），可搜訂單、顧客、電話、商品、貨號、物流單號 |
| 管理員 | 新增員工帳號，權限分「擁有者」和「員工」兩種，可停用帳號、重設密碼 |
| 操作紀錄 | 誰在什麼時候做了什麼 |

設定頁填的公司名稱、電話、地址等資料，會自動顯示在「關於我們」、「聯絡我們」、「購物須知」等頁面。

### 網站編輯（類似 Odoo）

管理員登入後，在任何頁面左下角按「編輯此頁」，就能直接修改文字、圖片、按鈕和連結；也可以在「網站 → 頁面」新增頁面、在「網站 → 選單」管理頁首和頁尾的連結。詳細說明請看 [`docs/網站編輯說明.md`](docs/網站編輯說明.md)。

### AI 搜尋優化（GEO／AEO／AIO）

後台「網站 → AI 搜尋優化」分成 GEO（生成式引擎）、AEO（答案引擎）、AIO（Google AI 摘要）三類，各自有優化程度分數、檢查項目、自動補齊（只補空白欄位，不覆蓋你寫的內容）和設定，可以分開調整；「成效追蹤」分頁記錄 AI 爬蟲造訪、從 AI 點進來的訪客和訂單。詳細說明請看 [`docs/AI搜尋優化說明.md`](docs/AI搜尋優化說明.md)。

### 管理員從前台登入

在前台「登入」頁用**管理員的 Email 和密碼**登入，會同時登入管理後台。右上角選單會出現「管理後台」，點了直接進入，不用再登入一次。從前台登出時，後台也會一起登出。
如果這個 Email 也註冊了會員（密碼相同），選單會同時有「管理後台」和「會員中心」。

### 自動處理

- 下單時自動扣庫存；取消訂單時自動把庫存加回去。
- 庫存不足時，客人無法下單超過庫存的數量，售完的商品會顯示「已售完」。
- 訪客用同一個 Email 註冊後，之前的訂單會自動歸到會員帳號下。
- 後台登入連續錯誤 5 次，會鎖定 10 分鐘。

## Google 試算表匯入

### 試算表格式

第一列是標題列，欄位順序不拘，只有「名稱」和「價格」是必填：

| 貨號 | 名稱 | 價格 | 原價 | 庫存 | 分類 | 品牌 | 簡介 | 圖片網址 | 許可證字號 | 上架 | 熱門 | 排序 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| FS-001 | 量子訊息多那之護膝 | 2800 | 3200 | 50 | 身體護具與支撐 | 愛放鬆 fun song | … | https://… | … | 是 | 是 | 1 |

- 匯入時以「貨號」比對既有商品；有相同貨號就更新，沒有就新增。沒有填貨號時，改用名稱比對。
- 可以填多個分類，用「、」或逗號隔開。試算表中出現、但網站上還沒有的分類和品牌，會自動建立。
- 圖片可以直接貼 Google 雲端硬碟的分享連結（檔案需設為「知道連結的任何人」可檢視）。
- 欄位留空時，不會覆蓋網站上原本的資料。
- 勾選「同步模式」時，試算表裡沒有的商品會自動下架。
- 後台「匯入商品」頁可以下載範本 CSV，也可以下載目前所有商品，匯入 Google 試算表後再修改。

### 連線設定（擇一）

先到 [Google Cloud Console](https://console.cloud.google.com/) 建立專案，並在「API 和服務 → 程式庫」啟用 **Google Sheets API**。

- **方法 A：API 金鑰（較簡單）**
  1. 到「憑證 → 建立憑證 → API 金鑰」，把金鑰貼到後台「設定 → Google 匯入」。
  2. 試算表要設為「知道連結的任何人都可以檢視」。
- **方法 B：服務帳戶（推薦，試算表可以保持私人）**
  1. 到「憑證 → 建立憑證 → 服務帳戶」，建立後進入該帳戶，在「金鑰 → 新增金鑰 → JSON」下載 .json 檔。
  2. 用記事本打開 .json 檔，把全部內容貼到後台設定。
  3. 在試算表按「共用」，把服務帳戶的 Email（`xxx@xxx.iam.gserviceaccount.com`）加為檢視者。

設定好後，可以按「測試連線」確認。

## 資料備份

所有資料都存在 `data/shop.db` 這個檔案，上傳的圖片存在 `public/uploads/` 資料夾。**定期備份這兩樣就好。**備份前請先關掉網站，避免複製到寫到一半的資料。

## 上線前請注意

- **線上刷卡**：目前客人選信用卡付款時，只會建立訂單，不會真的扣款。要在網站上直接刷卡，需要串接綠界或藍新金流（需要商店代號和金鑰）。
- **電子發票**：發票資訊會記在訂單上，實際開立仍需透過發票平台處理。
- **Email 通知**：目前網站不會自動寄出訂單確認信。如需要，可以串接 Gmail 或 SendGrid。
- **頁面內容**：「退換貨政策」、「條款」、「私隱政策」中還有幾處【方括號】文字，是需要你或律師確認的內容，請直接修改 `views/pages/` 裡對應的檔案。
- 請在 `.env` 設定 `SESSION_SECRET`，並把網站放在 HTTPS 後面。

## 專案結構

```
src/server.js         前台路由
src/admin.js          後台路由
src/store.js          前台資料存取
src/db.js             資料庫結構、網站設定、起始資料
src/google.js         Google 試算表 / CSV 匯入
views/pages/          前台頁面
views/admin/          後台頁面
public/               CSS、JS、圖片（uploads/ 是上傳的圖片）
data/shop.db          資料庫（第一次啟動時自動建立）
```
